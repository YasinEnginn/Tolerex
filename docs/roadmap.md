# Roadmap

## High Priority

1. Leader election and high availability
2. Write-ahead log and crash replay
3. Automatic replica repair and rebalancing
4. Rollback or repair of partial replica writes
5. Authenticated client protocol
6. Rootless containers with secure Compose secret ownership

## Medium Priority

1. Read replica and query optimizations
2. Compression, compaction, retention policies
3. Distributed tracing with OpenTelemetry

## Low Priority

1. REST API gateway
2. Admin dashboard
3. Multi-tenancy and namespaces

## Experimental

1. Geo-distributed replication
2. ML-assisted load balancing
